description: Stage all unstaged files and commit with a message.
argument-hint: <type(scope): subject> or <subject>
---

1.  Run the command `git add -A` to stage all unstaged and new files.
2.  After staging, use the user's message from `$ARGUMENTS` and follow all the instructions from the `/commit` command's definition file (`commands/commit.md`) to create the commit.
