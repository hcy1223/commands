# Factory Agent Commands

Factory AI agent 的 slash-commands 集合。

## 命令列表

| 命令 | 文件 | 说明 |
|------|------|------|
| `/add-commit` | [add-commit.md](add-commit.md) | Stage 所有未暂存文件并提交 |
| `/commit` | [commit.md](commit.md) | 提交已暂存的变更（支持 Conventional Commits） |
| `/create-implement-plan` | [create-implement-plan.md](create-implement-plan.md) | 为新功能生成技术实现方案 |
| `/create-task` | [create-task.md](create-task.md) | 将实现方案拆解为 TDD 任务清单 |
| `/refactor` | [refactor.md](refactor.md) | 重构命令 |
| `/revert-current` | [revert-current.md](revert-current.md) | 回退暂存和未暂存的变更 |
| `/task-status` | [task-status.md](task-status.md) | 显示任务文件的完成进度 |
